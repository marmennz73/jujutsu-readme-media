# Jujutsu Kaisen for Risk of Rain 2 · listing media

Images for the Thunderstore pages of the Jujutsu Kaisen survivor mods by Marmennz
(JujutsuKaisenCore and the character packages). Only media live here: no code, no
models, no sounds.

`media/<character>-<name>.gif` and `.jpg`: staged captures made with the mods' own
capture tool (14 October 2026) and, where the name carries `-play-`, gameplay
recorded by Marmennz. The mods' repository records every file's SHA-256 and checks
the hosted bytes before a README may link to it. Files are added and updated, never
deleted, because older package versions keep linking to them.

The mods are made with an AI assistant (Claude) under Marmennz's direction and are
tagged AI Generated on Thunderstore; the footage is real play. Jujutsu Kaisen and
Risk of Rain 2 and their assets belong to their owners; this is fan work for those
listings only.
